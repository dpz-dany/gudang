Gambar utama produk saja

Masukkan file mass_update_media_info…xlsx dari Shopee. Aplikasi mengambil kolom Foto Sampul, mengabaikan semua gambar produk tambahan dan gambar variasi, lalu membuat satu file ZIP.

Menyiapkan…

Nama file memakai SKU Induk. Jika SKU kosong atau sama, Kode Produk ditambahkan supaya tidak tertimpa. File Excel dan gambar tidak diunggah ke sistem gudang; prosesnya berlangsung di browser ini.
